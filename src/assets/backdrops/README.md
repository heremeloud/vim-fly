# backdrops

Optional hand-made tile per location, named `<zoneId>.png` (ruralRoad, bakery, cafes, mall, lawOffice, gym, courtroom, beach, residence, bakeLove).

- Size 480x200, seamless top to bottom (it repeats vertically while the dog climbs).
- Keep it soft and low-contrast so Vimmy and the items stay readable.
- A zone without a file falls back to the flat color + emoji tile.
